TeeToTum

Install the firmware on the Waveshare ESP32-S3 Knob Touch LCD 1.8 from this page. No toolchain, no command line.

This browser cannot talk to serial ports. Use desktop Chrome, Edge or Opera; Firefox and Safari cannot. Serial ports are only available on a page served over HTTPS.

Firmware version: see firmware/manifest.json

Before you start

  • Plug in the ESP32-S3, not the second chip. Which of the board's two chips is on USB depends on which way round the USB-C plug is inserted. The port to pick is USB JTAG/serial debug unit (303a:1001). If only a USB2.0-Serial or CH340 port appears, turn the plug over.
  • Chrome installed as a Flatpak on Linux needs one permission. Without it the browser cannot tell which device is on a port: the list shows only ttyACM0, and the install stops with “Failed to initialize”. Run flatpak override --user --filesystem=/run/udev:ro com.google.Chrome, quit Chrome completely and open this page again. For another Flatpak browser, use its app id.
  • Updating keeps your data. Settings, the haptics calibration and plugins installed in the flash slots stay where they are.
  • The first install replaces the factory demo for good. Nothing on this page can bring it back. If you want to keep that option, read an image of the flash first, as described in Restoring the factory firmware.
  • On a first install the dialog offers to erase the device. That clears the whole flash, including what the factory firmware left behind; it is the clean start.
