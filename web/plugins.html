TeeToTum plugins

Send a plugin to the knob over Bluetooth, from this page. The knob checks its signature and asks you before it installs anything.

This browser cannot talk to Bluetooth devices. Use Chrome, Edge or Opera on the desktop or Chrome on Android; Firefox and Safari cannot. On Linux, Chrome offers Bluetooth only with a flag: open chrome://flags/#enable-web-bluetooth, set Web Bluetooth to Enabled and restart the browser.

Before you start

  1. The knob needs a firmware that can receive: its Settings ring has a Receive entry. Firmware releases after 0.1.0 have it; the firmware installer installs the latest release.
  2. Open Settings > Receive on the knob and leave it open. The knob takes a plugin only while that dialog is on the glass.
  3. Pick a plugin below and choose Send to knob. The browser lists the knob as TeeToTum.
  4. The knob writes the plugin to a free slot and restarts. Confirm the install dialog on the glass; it shows who signed the plugin and what it may use.

What this page does not check

  • The signature. This page only reads which key a plugin names. Whether the signature holds is checked by the knob, before it offers the install.
  • Whether you trust the author. The catalogue lists plugins; it does not vouch for them. The key shown here and on the glass is the author's; the TeeToTum project signs with a key starting f6aca85edc3547d4.
